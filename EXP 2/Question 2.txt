Step 1: Start the program.

Step 2: Take input from the user for runs scored, balls faced, wickets taken, overs bowled, runs conceded, and number of catches.

SR = (runs / balls) × 100.

Step 4: Print the strike rate.

Step 5: Check the batting performance using conditions:

ER = runs conceded / overs.

Step 7: Print the economy rate.

If wickets ≥ 3 and ER ≤ 6, print "Excellent Bowler".

Else if wickets ≥ 2 and ER ≤ 8, print "Good Bowler".

Else if wickets ≥ 2, print "Average Bowler".

Otherwise print "Poor Bowler".

Step 9: Check the fielding performance based on number of catches.

Step 10: Based on batting and bowling performance, display the overall player performance.

Step 11: End the program.
