AIM: WAP to implement Matplotlib and Pandas


Algorithm:


Start.

Import pandas as pd and matplotlib.pyplot as plt.

Create a DataFrame using a dictionary representing categories (Month) and values (Sales).

Use plt.plot() to create a line chart using the columns from the DataFrame.

Add visual details such as xlabel, ylabel, and a title.

Apply markers and colors to make the graph readable.

Call plt.show() to render the window with the graph.

Stop.



Code:


import pandas as pd
import matplotlib.pyplot as plt

# 1. Prepare Data using Pandas
data = {
    'Month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    'Sales': [150, 200, 180, 250, 210]
}

df = pd.DataFrame(data)
print("Data for Plotting:")
print(df)

# 2. Visualize using Matplotlib
plt.plot(df['Month'], df['Sales'], marker='o', color='blue', linestyle='--')

# Adding labels and title
plt.xlabel('Months of the Year')
plt.ylabel('Sales Figure')
plt.title('Monthly Sales Performance')

# Display the plot
plt.show()
