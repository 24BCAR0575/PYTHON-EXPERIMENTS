Question 3: Write a program to implement various string operations


Algorithm:

Step 1: Start the program.

Step 2: Take a string input from the user.

Step 3: Display the original string.

Step 4: Find and display the length of the string using len() function.

Step 5: Convert the string to uppercase and display it.

Step 6: Convert the string to lowercase and display it.

Step 7: Display the string with the first letter capitalized.

Step 8: Replace a character in the string and display the modified string.

Step 9: Display substring using slicing (first few and last few characters).

Step 10: Check if a particular substring exists in the string.

Step 11: Count the occurrence of a character in the string.

Step 12: Find the position of a character in the string.

Step 13: Display the reversed string.

Step 14: End the program.


code:

# WAP to display various string operations in Python

s = input("Enter a string: ")

print("Original String:", s)

# Length of string
print("Length of string:", len(s))

# Uppercase
print("Uppercase:", s.upper())

# Lowercase
print("Lowercase:", s.lower())

# Capitalize
print("Capitalized:", s.capitalize())

# Replace
print("Replace a with @:", s.replace('a','@'))

# String slicing
print("First 3 characters:", s[:3])
print("Last 3 characters:", s[-3:])

# Check substring
print("Contains 'python':", "python" in s)

# Count characters
print("Count of letter 'a':", s.count('a'))

# Find position
print("Position of first 'a':", s.find('a'))

# Reverse string
print("Reversed string:", s[::-1])
