AIM: WAP to load, clean, and explore data using Python (Pandas).




Algorithm:

Start.

Import the pandas library as pd.

Define a dictionary containing sample data with missing values (None).

Create a Pandas DataFrame using pd.DataFrame().

Display the original data and basic exploration using head() and info().

Check for missing values using isnull().sum().

Clean the data by removing rows with missing values using dropna().

Display the cleaned data and summary statistics using describe().

Stop.




Code:

import pandas as pd

# Creating the dataset with missing values
data = {
    "Name": ["A", "B", "C", "D", "E"],
    "Marks": [80, 75, None, 90, 85],
    "Age": [20, 21, 19, None, 22]
}

df = pd.DataFrame(data)

print("Original Data:")
print(df)

print("\nFirst 5 rows:")
print(df.head())

print("\nData Info:")
df.info()

print("\nMissing values:")
print(df.isnull().sum())

# Data Cleaning
df_clean = df.dropna()

print("\nCleaned Data:")
print(df_clean)

print("\nSummary Statistics:")
print(df_clean.describe())
